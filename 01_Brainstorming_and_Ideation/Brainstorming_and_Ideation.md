# Brainstorming and Ideation

## Project Title

Auto-Ticket Classification using Flow Designer

## Problem Identification

School IT helpdesks receive different types of incidents such as Wi-Fi
issues, projector failures, password problems, and slow computers.

Manually reviewing and assigning categories to every incident requires
additional time and effort.

## Proposed Idea

The proposed project uses ServiceNow Flow Designer to automatically
classify IT tickets based on keywords present in the ticket description.

## Main Idea

Student creates an IT ticket
↓
Flow Designer checks the ticket description
↓
Keywords are identified
↓
Category is automatically assigned
↓
Subcategory is automatically assigned
↓
Email notification is sent

## Objectives

- Automatically classify IT incidents.
- Reduce manual classification work.
- Improve ticket routing efficiency.
- Maintain the solution using Flow Designer.
- Improve consistency in ticket classification.

# Requirement Analysis

## Project Title

Auto-Ticket Classification using Flow Designer

## Existing Process

The school IT helpdesk receives different types of IT incidents.

The helpdesk staff manually:

1. Identify the issue.
2. Review the ticket.
3. Select the appropriate category.
4. Select the appropriate subcategory.
5. Inform the caller.

## Business Requirements

The system should:

- Automatically classify incidents.
- Automatically assign Category.
- Automatically assign Subcategory.
- Maintain dependent Category and Subcategory choices.
- Send an automated email notification.
- Store ticket information properly.
- Be easy to maintain and extend.
